### 🚀 What I'm building

| Project | What it does | Stack |
|---|---|---|
| **beltcounter** | A production-line counter service. Devices on the factory floor report how many products passed a belt; the service buffers those increments in Redis and flushes periodic summaries to MySQL, so the database stays calm no matter how fast the events arrive. | Go · Redis · MySQL · Docker |
| **ERP / MES web app** | Internal web application for production tracking and reporting. | Laravel · Blade · MySQL |
| **PMTP** | Desktop application coursework built on the .NET stack. | C# · .NET |
